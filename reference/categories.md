# Claude Space Categories

Reference list of workspace categories for template generation. Use these to suggest appropriate templates or to classify user requests.

## Environment Management
System administration — local and remote machine management.
Examples: Linux Desktop Manager, Home Folder Admin, Conda Manager, Security Auditor, Remote Machine Admin, LAN Manager.

## DevOps & Infrastructure
Container orchestration, CI/CD, backup/recovery, monitoring.

## Data & Analytics
ETL workflows, database admin, ML experiments, scientific computing.

## Media Processing
Video, audio, and image processing workflows (ffmpeg, Sox, etc.).

## Content & Documentation
Technical writing, API docs, blog management, book writing, podcast production.

## Research
Deep research, literature review, market research, user research.

## Business Operations
Job hunting, career development, client projects, proposals, meetings, SMB management, inventory, financial planning, grant writing, business development.

## Personal Development
Philosophy, personal growth, health tracking, therapy journaling, fitness, meal planning.

## Education & Learning
Curriculum development, student support, language learning, skill development, reading lists.

## Creative Projects
3D design, graphic design, animation, music production, sound design, game design, mod development.

## Home & Lifestyle
Home renovation/improvement, gardening, recipes, travel, parenting, media curation.

## Troubleshooting & Support
Desktop debugging, software troubleshooting, hardware diagnostics.

## Legal & Compliance
Contract management, compliance tracking.

## Event Management
Event planning, conference organization.
